## 1. 基础设定

- 牌 **136 张**：万、条、筒 各 1–9 × 4 = 108；东、南、西、北、中、发、白 × 4 = 28。
- 4 人局，座次东、南、西、北，逆时针行牌。
- **轮庄**：东起庄；**庄家胡牌连庄**；闲家胡牌则下一轮庄家轮到庄的下家；**流局（荒庄）庄家继续**。
- **底分**：庄家 2、闲家 1；**庄家胡牌时，所有付款方底分均按 2**（算子表基础规则）。
- **精的轮转（分组独立循环；副精 = 正精在本组内的下一张）**：万 1→2→…→9→**1**（条、筒同理，均为 1-9-1）；东→南→西→北→**东**；中→发→白→**中**。**组与组之间不跨越**——例：正精 9 万 → 副精 1 万；正精 北 → 副精 东；正精 白 → 副精 中。

## 2. 精（赖子）

### 2.1 翻精

- 每局**抓牌动画结束后**，庄家在桌面正中**再点一次「掷骰翻精」**掷两颗骰子：
  - **两骰点数之和 S**，从**摸牌处**起**逆时针**数 S 列 → 第 S 列的**上层那张牌**翻开 = **正精**；**摸牌处那一墩已被抓走，从它逆时针方向第一个完整墩起为第 1 列**（例：5+3=8 → 摸牌处逆时针第 8 墩的上层；和数 10 → 第 10 墩）；
  - **副精** = 正精在本组内的下一张（§1 轮转规则，按牌面值推定）。
- 翻出的正精**在牌墙上原位翻面显示**（面朝上），不取出、牌墙张数不变：可被后续正常摸走，也可被杠骰投到。
- 翻精骰掷出前，正精/副精对所有玩家隐藏（防剧透）；骰子翻滚动画定格时才揭示点数与精牌。
- **杠后不重翻**。

### 2.2 精的性质

- 胡牌判定中可当任意牌（万能牌）。
- **不能**当任意牌去吃、碰、杠；只能按**本身牌面**参与（例：正精是「中」，可拿两张「中」碰别人打出的「中」）。
- 被吃、碰（含明杠）进入副露的精：**只计分，锁死在副露，不参与万能胡**。

### 2.3 精的归属（冲关点数用）

每张精在同一时刻只归一家，不重复计：

| 精所在位置 | 归谁 |
|---|---|
| 某家手牌 | 该家 |
| 某家副露（吃 / 碰 / 杠） | 吃、碰、杠者 |
| 某家牌河（打出后无人吃碰） | **打出者**（打出的精也算分） |
| 点炮的那张牌 | **赢家**（计入赢家胡牌型，避免两家重复计分） |

- 点数：**正精每张 2 点，副精每张 1点**。
- 翻出的那张正精在被摸走前不属于任何人、不计点；被谁摸走（或骰子补杠投到）就归谁（§2.1）。

## 3. 吃、碰、杠

- **只能吃上家**；标准牌吃法不变（12 吃 3、23 吃 1 或 4 …）。
- **字牌顺子**：
  - 任意 **3 种不同的风** 为一组（东南西、东南北、东西北、南西北 均算）；
  - 中、发、白 三种为一组。
- **风牌吃**：手里任意 2 种风 + 上家打第 3 种即可吃。手里【东、东】+ 上家打【南】**不能**吃（须 3 种不同）。
- 碰：任意两张相同 + 别家打出第三张；杠：明杠 / 暗杠 / 补杠（精只能按本身牌面参与，§2.2）。
- **补杠抓牌**：「掷骰补杠」开关（默认开）——杠后杠者在桌面正中**点击「掷骰补牌」掷两颗骰子**（动画展示点数）：**与翻精同一公式**——和数 S，从摸牌处起逆时针数 S 列（摸牌处空墩不计，其后首个完整墩为第 1 列），**上层在取上层，上层已取则取下层**；开关关 = 摸倒数第一张。
- **没有抢杠胡**。
- 精参与吃碰杠只能按本身牌面（§2.2）。

## 4. 胡牌判定

| 牌型 | 条件 |
|---|---|
| 平胡 | 3 面子 + 1 将；面子 = 顺子（含字牌组）或刻子 |
| 精吊 | 胡牌前的 13 张：摸牌墙中**剩余可摸的任何一种牌**都能胡（必含精）；**只能自摸** |
| 小7对 | 无碰、无吃、**无杠**，手牌 7 个对子（4 张相同按 2 对计） |
| 大7对 | **4 刻 1 将**，可碰、可杠、不可吃、无顺子 |
| 十三烂 | **14 张全单张**：无对子、数牌同花色间隔 ≥2 张、字牌可成串；细则见下；**不能精吊** |
| 天胡 | 庄家起手 14 张即胡 |
| 地胡 | 胡庄家打出的**第一张牌**（仅此一种，不含闲家首轮自摸） |
| 德国 | 胡牌分解中**没有任何精被当万能牌用**；精按本身面值参与也算德国，且这张精照计冲关点数 |
| 德中德 | 德国成立，**且其余三家归属精（手牌 + 副露 + 牌河）全为 0** |

**十三烂细则**：

- 14 张（含副露）**每种至多一张**，全局无对子。
- 万、条、筒：**同花色内**任意两张至少隔 2 张（差 ≥3）——如 147、258、369，或 159 这类满足间隔的组合；因此数牌顺子不可能出现。**跨花色之间不限**（1 筒与 1 万可共存）。
- 东南西北中发白：**不受间隔限制**，可相邻成串（字牌顺子允许，可吃成串），但每种至多一张。
- **七星十三烂** = 十三烂 + 东南西北中发白 七张齐全。
- **德国七星十三烂** = 七星十三烂成立，且精只按本身面值参与、未当万能牌（即德国）。
- 精可当万能牌补缺张；用了万能 → 该局非德国。
- 以十三烂为目标时：吃数牌、碰任何牌都会破坏间隔或对子要求，实际只有字牌成串的吃可行。

- **一炮只一响**：同一张牌多人可胡时，等齐所有可胡玩家的应答（确认或放弃）后，按**从庄家起的座位顺序**（庄 → 下家 → 对家 → 上家）取**第一个**点「胡」且牌型有效的玩家结算；前面的玩家不胡（过 / 超时 / 改吃碰杠）才轮到后面（并发锁全流程见 §5.1）。
- **精吊 与 德国 可并存**：例——四组面子齐 + 手里单一张精，只有摸到精本身的牌面时，精按本身做将 → 既是精吊又是德国；摸其他牌用万能代就只算精吊。
- 精吊用「牌墙里还能摸到的牌种」判定，绝张不参与。

## 5. 对局流程与裁决

```
开局仪式（庄家点桌面正中「掷骰开局」→ 双骰动画 → 定起牌位）→ 洗牌发牌（带抓牌动画）
→ 翻精仪式（抓牌完 → 庄家再点「掷骰翻精」→ 和数定位、正精原位翻面）→ 行牌（摸 / 打）
→ 出牌后进入响应窗口 15 秒（所有能操作的人同时拿到全部选项：胡 / 杠 / 碰 / 吃）
→ 全部应答或超时后按优先级裁决：胡 > 杠 > 碰 > 吃；多人可胡时按庄位顺序取第一个点「胡」的 —— 一炮只一响
  （**只有一人能胡**时：有人点「胡」立即结算，不等其他人；**多人能胡**时：等可胡者应答齐后按
  **从庄家起的座位顺序**由前者胡——前面的玩家不胡（过 / 超时），才轮到后面。2026-10-16 定版，与赣州冲关一致）
→ 全过 / 无人响应 → 下家摸牌
→ 杠 → 杠者点桌面正中「掷骰补牌」→ 动画后按和数定位补牌（§3）
→ 有人胡 → 摊牌 + 结算（§6）→ 下一局轮庄（庄家胡牌连庄）
→ 牌墙摸完 → 流局 → 庄家继续
```

- **牌墙环**：136 张按**上下两层**码成 68 墩，绕桌摆 4 段并**内移成方形**（庄前与对家前为**长段 20 墩**、上下家前为**短段 14 墩**，段间留角隙），位于手牌与牌河之间；牌背亮蓝、墩下加深色槽影，与深绿桌布明确区分；开局、摸牌、杠补均在牌墙上**动画减少**对应墩数，并有牌背飞向玩家的动画。
  - **四段随庄家视角旋转**（庄家在自己上/下家方位时，长段会落到左右两边）。此时段内墩距**自动压缩**到「整段刚好停在手牌之上」（约 440px），保证牌墙永不覆压手牌——2026-10-15 修正（此前长段竖放时会长达 ≈592px，一直伸进手牌带，手牌外侧的牌被牌堆挡掉）。横段墩距不变。
- **中央信息区**：**东南西北罗盘**——四个方位显示四家风位（镜像视角），**坐庄者金色高亮**；**正中间两颗骰子**清晰显示点数（未掷为 `?`，翻滚动画期间滚动、定格才揭示）；**正精 / 副精明牌摆在桌面上**；左上角显示牌墙剩余；**掷骰按钮（开局 / 翻精 / 补牌）显示在桌面正中**（覆盖骰子位，仅授权者可点）。
- **开局掷骰仪式**：庄家点桌面正中「掷骰开局」→ 两颗骰子翻滚动画 → 展示点数：
  - **两骰点数之和 S**：从庄家（=1）起**逆时针**循环数到的座位——S≡1 庄、S≡2 下家、S≡3 对家、S≡4 上家、S≡5 又回到庄（例 庄为东时 S=4 → 北 / S=5 → 东）；
  - **小点数**：在该座位面前的牌墙上，**顺时针**空出小点数列、从**下一列**开始抓牌（例 4、1 → 和 5≡1 → 庄家门前，空 1 列、第 2 列起牌；牌墙行进/列序均为顺时针，座位按和数逆时针循环）；
  - 掷骰动画期间禁止出牌；**未点击不自动掷**——庄家（或杠者）不点就一直等待、对局卡住，无任何超时代掷。
- **翻精仪式**：抓牌动画结束后进入翻精等待——庄家点「掷骰翻精」（规则见 §2.1：和数 S、摸牌处逆时针第 S 列上层）；揭示前正/副精对所有人隐藏。
- **发牌顺序**（4×4×4）：每次抓**2 墩（上下两层 = 4 张）**，**顺时针**轮转（庄 → 上家 → 对家 → 下家），共 **3 轮 = 每人 12 张**；随后**庄家跳子**：从上面一层**隔一墩**取 2 张（庄共 14 张）；闲家按顺时针各补 1 张（各 13 张）。数骰子逆时针、摸牌顺时针。

- **过水**：过胡（含超时未应）后，到自己摸牌前不能再点炮胡；自摸不受限。
- **点炮的精按本身**：别人打出的精参与点炮胡时只能当其牌面、不得万能代牌；自己手牌里的精仍可万能。
- **胡/自摸按钮显示特殊牌型名**（如 `胡·德国·地胡`、`自摸·精吊·天胡`），普通平胡显示普通按钮。
- 座位号固定（0/1/2/3 = 东/南/西/北 的**座位基准序**），但**风位随庄**：庄家显示「东」，其余按座位顺序顺延（南 / 西 / 北）；**庄轮转时四家风位随之旋转**。牌桌按每个玩家的视角**镜像**（自己永远在正下方，下家在右、对家在上、上家在左）。
- **首局定庄**：大厅里四人**各掷两骰**（每人一次），**点数最大者坐庄**；点数相同者并列重掷。四人全部掷完才定庄，**未定庄不能开局**；先「准备」后掷骰也可以（定庄一完成、四人齐备即自动开局）。后续按 §1 的轮庄规则接庄。
- **入口分步向导（v1.21）**：进入首页是一条**分步导航**，顶部步骤条始终显示当前位置与进度，**顺序为「先决定创建还是加入，再选玩法」**：
  - **第 ① 步 · 创建 / 加入**：二选一（创建房间 / 加入房间），这一步决定后面还有几步、以及最后一步是哪个表单；
  - **第 ② 步 · 选择玩法**（**仅「创建房间」分支**）：从**玩法注册表**列出可选玩法（卡片含简介与标签，默认选中上次所选）；
  - **最后一步 · 填写信息**：创建 → 昵称 + 「创建房间」（摘要「玩法 <所选玩法>」+「成为房主（东家）」）；加入 → 昵称 + 6 位房间码 + 「加入房间」（摘要「玩法 由房间决定」+「加入已有房间」）。
  - **加入分支只有 2 步**：玩法由房间决定，让用户选会误导，故「选择玩法」这一步在加入分支**不存在**；步骤条按分支**动态渲染并重新编号**（创建 1/2/3、加入 1/2）。
  - **步骤条**：`当前`（金色实心圆）→ `已完成`（绿色、**可点击回退**）→ `未开始`（灰色）；每步的选择都会决定后续界面。
  - **邀请链接直达**（`?room=`）：模式步由房间决定，标记为**已锁定**（不可回退）并**直接落到最后的加入表单**（2 步形态），房间码预填且只读；提交后进入房间。
  - 离开房间 / 房间解散后回到**第 ① 步**（玩法选择保留），并解除邀请锁定。
- **准备阶段换位（v1.19）**：大厅（准备阶段）点**其他座位**即可换位——① **空位**：直接搬过去，无需任何人同意；② **有人**：向对方发起**换位请求**，对方弹窗点「同意 / 拒绝」；同意则两人座位互换，拒绝则双方留在原位。**房主身份与下一局庄家随人迁移**（不随座位号）；同一时刻只允许一个待处理请求；对方已准备、或对局已开始、或请求者在展示结算中时不能交换。请求处理期间任一方离开房间 → 请求自动作废并通知对方。
- 大厅可点**分享链接**：`http://主机地址/?room=房间码` —— 朋友打开后进入导航向导的**第 ② 步（加入房间表单）**，**房号已预填且可修改**；步骤条上已完成步骤可点、表单下方有「上一步」，可随时返回改选**创建房间 / 加入房间**（返回创建时自动清掉链接里的 `?room=`，避免与新房号冲突）。昵称填过一次即记住，再次打开直接进房。
- 响应期间显示 **15 秒倒计时**（一个窗口共享），状态栏提示仍在应答的玩家。
- 牌桌逻辑画布 **1280×640（2:1）**，按视口高度自适应收缩——**一页展示，页面不出滚动条**；手牌 52×70。
- **房间累计积分**每局累加，显示在昵称旁（大厅座位卡、牌桌名牌右侧、结算表「累计」列）。
- **牌桌名牌（座位角标）贴在四个桌角**（2026-10-15 调整）：取「该玩家**自己左手边**的桌角」——自己（下方）**左下**、下家（右方）**右下**、对家（上方）**右上**、上家（左方）**左上**（即「下→左下、右→右下、上→右上、左→左上」）。玩家都朝向桌心，其左手方向即屏幕上的左下/右下/右上/左上，故四角一一对应；名牌随视角镜像一起旋转，任一玩家看到**自己那枚恒在左下角**。
- **局内聊天框**（右下角）：**默认最小化**——只留「聊天」标题栏，点标题栏右侧按钮展开 / 收起（桌面端与移动端一致）。展开后有消息记录、**表情**（6 列网格弹层）与**快捷语**（点击即发送）两个互斥弹层；**表情与快捷语都是点击即发送**，不会写进输入框（2026-10-15 改：表情此前会插入输入框，需再点一次「发送」）；**最小化时两个弹层一并关闭**，与其状态保持一致（2026-10-15 修：表情面板此前会残留显示）。
- **收起态未读提醒**：最小化时收到**别人**的消息，标题栏会亮出红色未读角标（显示条数，>99 显示「99+」；手机上收起态是个 46×46 圆钮，角标挂在圆钮右上角）；**展开即清空**，展开着的时候收到消息不计数（人就在看着）。2026-10-15 加——默认最小化后很容易漏消息。

### 5.1 胡牌并发锁（一炮多响的响应窗口）

一张牌触发多名玩家同时满足胡牌条件时，系统按以下口径执行——**响应窗口本身就是锁**：

- **锁的粒度**：一次出牌（或补杠开的抢杠窗口）申请**一把锁** = 一个响应窗口，覆盖所有对这张牌有操作资格的座位。窗口存在期间，任何一家的**出牌 / 自摸 / 暗杠 / 补杠一律被拒绝**（不等窗口结束就无法行牌）；锁只在「所有有资格者都已完成应答」或「窗口超时」时释放，二选一，没有第三种出口。
- **等待期间的状态同步**：窗口内每位有资格者**同时**拿到自己的全部选项（胡 / 杠 / 碰 / 吃，胡按钮带特殊牌型名）；「仍在应答」列表只列**尚未应答**的座位，谁应了答马上从列表消失；15 秒倒计时是**全窗口共享的一个截止时间**（不因中途有人应答而续期）；出牌者本人无选项，也不能做任何动作。
- **多人响应超时处理**：超时未应答者一律记「过」——有胡选项的**同时记过水**（§4：到自己摸牌前不能再点炮胡，自摸不受限）。超时与主动点「过」完全等价，不区分是否故意；记过后该座位在本窗口内不再等待。
- **按庄位顺序执行胡牌**：收齐应答后，把所有「胡」请求按**从庄家起的座位顺序**（庄家 → 下家 → 对家 → 上家）排序，取**第一个**且牌型仍有效的玩家结算；其余玩家的「胡」作废（不结算、也不记过水——他们点的是「胡」不是「过」）。庄位顺序中排在前面的人若选了「过 / 杠 / 碰 / 吃」或超时，顺延到下一名点「胡」的玩家。**只有一人能胡**时例外：该玩家点「胡」立即结算，不等其他人（胡的优先级最高，后续的杠 / 碰 / 吃应答不可能翻盘）。
- **抢杠窗口同理**（仅赣州；南昌没有抢杠胡，§3）：补杠被抢时窗口内只有「胡」一种选项，同样等齐或超时后按庄位顺序取第一个（补杠撤回、不计杠分、不补牌）。

#### 锁的数据结构与状态机

实现见 `packages/shared/src/hu-lock.ts`（纯结构，可单测）；`Pending.huLock` 与响应窗口同生命周期。

| 字段 | 含义 |
|---|---|
| `tile` / `from` | 被争夺的点炮牌与出牌者（补杠抢杠窗口里是杠牌与杠者） |
| `holder` | 持有者：第一个点胡者登记为**暂定**持有；被更靠前的座位抢占则易主 |
| `granted` | 是否已终局（窗口收齐或超时后置位，此后所有加锁尝试一律 `closed`） |
| `attempts` | 按到达顺序记录的全部胡牌请求（回执 / 审计用） |
| `denied` | 被锁排除、**本张牌不能胡**的座位 |

加锁应答 `attempt(seat)` 的四种结果：

| 结果 | 触发条件 | 语义 |
|---|---|---|
| `tentative` | 尚无持有者 | 登记为暂定持有者（**不因点击在先而终局**） |
| `preempted` | 新请求比当前持有者**更靠前**（庄位顺序） | 抢占成功：原持有者转入 `denied`，本张牌不能再胡 |
| `denied` | 新请求比当前持有者更靠后 | 本张牌不能胡（请求仍登记，供结算回执） |
| `duplicate` | 本窗口该座位已点过胡 | 拒绝且状态不变（`respond()` 层报「已经操作过了」） |
| `closed` | 窗口已终局 | 并发点胡里后到的请求一律拒绝，状态不变 |

**处理流程**（一次出牌）：`discard()` / `openRobWindow()` 建锁 → 有人点「胡」则 `attempt()`
（登记 / 抢占 / 排除）→ ① 窗口内还有别的可胡者未应答 → 继续等；② 已无别的可胡者、或窗口超时
→ `finalize()` 定锁（幂等）：`holder` 即赢家、`denied` 即「本张牌不能胡」的玩家 → 结算回执
（结算面板「胡牌锁」一行 + 牌桌播报「一炮一响：本张牌由 X 胡，其余 N 家的胡牌请求被锁排除」）。

**被锁排除 ≠ 过水**：排除只意味着「不能胡这一张」，不触发 §4 过水（过水只由「过 / 超时」产生）。

## 6. 算分

### 6.1 公式

```
每家应付 = 底数 × M × 翻倍 +（5 若 +5 条件命中）
```

- **底数**：庄家胡 → 全体付款方按 2；闲家胡 → 庄 2、闲 1
- **翻倍**：自摸 → 全体付款方 ×2；放炮 → 点炮者 ×2，其余 ×1
  - 例外：**三段「杠开」的 M 已含自摸 ×2，不再另乘**
- **+5**：自摸 → 全体付款方；放炮 → 仅点炮者（对应德国、精吊等带 +5 的牌型；房间开关可关，关闭只去 +5、倍数不变）
- 守恒：赢家进子 = 三家出子之和

### 6.3 精点结算（冲关）

- **胡牌结束后**计算；点数 = 归属**正精 × 2 + 副精 × 1**（归属见 §2.3：手牌 + 副露 + 自家牌河，点炮的精归赢家）。
- **逐对结算**：四家两两比较（共 6 对），点差 **d = |a − b|**：
  - **d ≥ 2** → 点数**低**的一方向**高**的付 **d × max(d − 3, 2)** 子
  - **d ≤ 1** → 该对不结算
- 例：东1、南2、西1、北0 → 仅南↔北点差 2 → 北付南 `2 × 2 = 4` 子（南 +4、北 −4，东/西平）。
- 对方 0 点时与旧表一致：d=5→10、6→18、7→28、8→40、9→54、10→70、11→88、12→108；**d=3→6、d=4→8**（同式导出）。
- 只在**有人胡牌时**结算，流局不算；杠精另行（§6.4）。

### 6.4 杠精

- 杠的那张是**正精** → 奖励 20 子；**副精** → 奖励 10 子；明杠、暗杠、补杠均触发。
- 其余三家出：**每家各出一份**（杠正精 → 杠者收 60；杠副精 → 杠者收 30）。
- 不再附带附注里的"本身点数"和霸王精（按你简化后的定义）。

### 6.5 算子表未覆盖组合的取值

- 判定与取值以 `packages/shared/src/score.ts` 的 `classifyPattern` 为准（覆盖 §6.2 全部 30 行）。
- **德中德未单列**的组合（如小7对 / 十三烂的德中德）：按对应**德国行 × 2**（保留 +5）。
- 互斥而不可能出现的组合不设行：小7对无杠（杠开组合不存在）、十三烂无杠且不能精吊。

### 6.6 结算流程（M4）

- 有人胡牌 → 服务端计算 **牌型子 + 冲关 + 杠精** → 向四家推送结算面板：每家的**正精/副精张数**、**胡牌（牌型）分**、**冲关分**、**杠精分**、**本局合计**，以及冲关/杠精说明与**累计子**。
- **摊牌**：胡牌后不立即回大厅——牌桌保留并**亮出四家手牌**，结算面板浮于其上。
- **赢家标识**：摊牌时**显著标识谁胡了**——画布顶部金色横幅点名 `风位·昵称 胡`（副行显示牌型），赢家手牌区金色发光框，赢家名牌金色高亮并标「胡牌！」。
- 结算面板两个按钮：**最小化**（收起面板看牌，右下角「本局结算 ▲」可再展开）；**下一局**（回大厅并**默认已就绪**，四人就绪后自动开下一局）。结算面板**不铺全屏遮罩**，收起前底下的摊牌（四家亮出的手牌 + 牌河）也不被压暗。
- 天地胡：固定每家 20（精吊天地 40），**不叠**其他牌型分；冲关、杠精照常叠加。
- 点炮的精按 §2.3 归赢家后再计冲关点数。
- 房间累计子跨局保留（同座位换人沿用）。
- 全部结算零和：四家净变动之和恒为 0（结算实现保证，验收时人工抽查）。
